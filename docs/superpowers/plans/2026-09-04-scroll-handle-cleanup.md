# 滚动手柄清理 Implementation Plan

**Goal:** 删除旧蓝色边缘条，让单一内容滚动手柄在移动/窄屏环境可靠可见。

**Architecture:** 用独立 `#scrollHandle` 替换复用的 `#edgeR`，删除旧边缘导航输入层；继续复用既有安全滚动通信与手势模块。

## 步骤

- [ ] 在 `server/api/test/frontend-scroll.js` 增加旧控件彻底删除、独立手柄和响应式能力判断的失败测试。
- [ ] 修改 `index.html` 的 DOM、CSS 和初始化逻辑，删除旧边缘手势并接入独立手柄。
- [ ] 更新预览说明和交付文档，明确不能用 `file://` 验证跨域滚动协议。
- [ ] 运行滚动专项测试、预览测试、完整测试、语法与差异检查。
- [ ] 使用独立 headless 会话验证窄屏精细指针、移动触摸、三个试点、无溢出/面板、桌面回归。
- [ ] 启动仅监听本机的 HTTP 预览并交付链接；不提交、推送或部署。
