# 单一内容滚动手柄 Implementation Plan

> 执行方式：当前隔离工作树内连续执行，用户已批准设计并明确 go。不提交、推送或部署；不重新创建工作树，不改公开实验。使用测试先行、逐项验证的执行流程。

**Goal:** 移动端只保留一个中性短手柄，专门滚动当前实验；实验切换使用按钮与目录。

**Architecture:** 保留已验证的宿主/iframe 滚动协议、来源与会话校验及遮罩判断。仅收敛宿主外观和输入分流；不改变实验接收器或器材代码。原始桌面交互不变，本机预览继续模拟移动指针。

**Tech Stack:** 原有 HTML/CSS/JavaScript、Node 内置测试、隔离 headless Playwright。

## 已确认设计

- 移动端隐藏并停用整个左侧手势区，不能留下不可见的拦截区域；顶部“我的”按钮继续可用。
- 右侧采用约 96px 高的半透明中性灰短手柄、中心 ↕；透明触摸区域 26×112px，固定在可用区域中部，避开顶部/底部控件。
- 独立复核补充：矮屏缩短触摸区域，小于 44px 时隐藏并停用，避免与翻页按钮重叠。
- 保留指针捕获，手指移出短手柄后仍能连续拖动；手柄自身不随进度移动。
- 点击不跳页，横向拖动不打开目录；纵向拖动、键盘以及手柄上的滚轮仅滚动当前内容。
- 保留无溢出/未适配/遮罩/切换时停用，以及键盘可访问的滚动语义。
