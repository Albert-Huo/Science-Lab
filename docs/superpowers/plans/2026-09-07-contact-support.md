# 联系反馈与自愿赞赏

目标：保持免费、免登录的实验体验，加入视觉协调、易于找到的联系和赞赏入口。用户已完成本地验收，并于 2026-09-07 明确授权提交、推送和上线。

设计：沿用深蓝底色、青绿色联系入口与低饱和暖色赞赏入口。目录底部常驻两个按钮，“我的 → 信息”提供联系卡入口。主动点击打开原生 dialog；桌面居中，手机贴底。赞赏码使用用户提供的原始 JPG，不裁切、不重绘。复制失败时选中可读微信号，给出手动复制提示。

用户补充：赞赏标题为“自愿支持项目维护”，明确全部功能免费、支持与否/金额不影响服务、不提供会员/专属内容/优先服务或其他回报。未满18周岁勿支付；误付款由监护人通过可点击的联系方式处理。用户已确认收款方完整名称为“北京星年科技中心”，页面据此展示。桌面说明与二维码左右排列，手机纵向排列。
