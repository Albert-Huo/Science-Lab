# 移动端滚动手柄清理设计

日期：2026-09-04

## 问题与证据

- 旧实验切换边缘条与新内容滚动手柄共用 `#edgeR`，外观与输入职责耦合。
- 在 390×844 窄屏、`pointer: coarse` 为 false 的浏览器中，旧 `.rail` 为可见且可触摸，新 `.scroll-grip` 为隐藏；这与用户看到“小蓝条但看不到新手柄”一致。
- `file://` 页面没有可信父页面来源，实验接收器按安全设计拒绝握手；必须通过正式 HTTPS 或本地 HTTP 预览验证。

## 设计

- 删除 `#edgeL`、旧 `.rail`、`attachEdge` 及其左右边缘切换/开面板手势；实验切换只使用右下角箭头和顶部目录。
- 新建职责单一的 `#scrollHandle`。透明触摸区与中性半透明可视胶囊分离，不再复用旧边缘容器。
- 在窄屏（最大 899px）或设备存在粗指针时启用滚动协议，兼容手机横屏、平板、混合触控设备和窄屏桌面预览。
- 手柄仅在当前实验已适配、有纵向溢出、无弹窗/面板且页面可见时显示；无效状态不展示不可点击的假控件。
- 可视部分保持细小，以深灰半透明底、浅色边框和 `↕` 提示增强辨识度；按下时只提高中性色对比度，不使用蓝色。
- 保留来源、窗口、会话、数值校验、指针捕获、键盘和手柄滚轮行为；不修改实验器材或 iframe 接收器。

## 验收

- 源码中不存在旧边缘条、`.rail`、`attachEdge` 或边缘切换事件。
- 390px 窄屏的精细指针浏览器在实验 1、35、41 有溢出时显示新手柄，并可用鼠标/触摸纵向拖动。
- 手柄轻点、横向拖动不切换实验；左、右边缘不再存在隐藏拦截区。
- 900px 以上且无触摸能力的桌面不显示手柄；箭头、目录、桌面滚轮/方向键翻实验保持正常。
- 完整自动化测试和三个试点实验浏览器回归通过后，只提供本地 HTTP 预览，不提交、推送或部署。
