# 当前实验内容滚动带：本地试点

用户已确认：复用右侧边缘区域滚动当前实验，先验证 2–3 个实验。本轮只交付本地预览，不提交、推送或部署。

- 右侧只显示中性半透明的短小 ↕ 手柄，不再绘制进度轨道；常规视口下可见手柄 14×96px、透明触摸区域 26×112px。上滑查看下方内容，下滑查看上方。
- 矮屏按可用高度缩短手柄，避开顶部栏和右下角按钮；触摸目标高度小于 44px 时隐藏并停用。
- 触摸设备的左右旧边缘手势均停用，左侧整个触摸层隐藏，不能留下不可见的拦截区域。右侧手柄只滚动内容；顶部/底部不串到下一实验。切换使用导航按钮和目录，“我的/AI”使用顶部按钮。
- 桌面原有交互保持；不支持协议、无溢出或打开面板时隐藏滚动带。
- 仅当前 iframe 可通信，校验 origin、source、协议、会话和有限数值；所有 postMessage 指定确切来源。
- 手势按轴锁定，处理取消/失去捕获/切换页面；拖出短手柄仍通过捕获继续滚动。横滑和轻点均无动作。键盘支持方向键和 PageUp/PageDown/Home/End；手柄上的滚轮只作用于当前内容，保留浏览器缩放手势。
- 实验 1、35、41 在本地预览响应中加载接收器，不改公开 HTML 字节、器材、公式、步骤、面板或演示代码。
- 原生 document.scrollingElement 为默认目标；显式指定内部容器的能力用隔离测试验证，不猜测每个实验的滚动目标。
- 预览服务器仅监听本机，仅暴露 App 运行文件与公开内容目录，禁用缓存/SW，防止旧页面与新协议混用。
- 后续真实发布须另行把接收器接入实验内容站，并同步静态部署清单及缓存版本；本地试点不能当作全站上线。

验收：三个试点上下滚动到边界不换实验；canvas 仍可操作；面板开关、切换/重载、无协议页、伪造消息、桌面和移动视口；现有测试不回归。
