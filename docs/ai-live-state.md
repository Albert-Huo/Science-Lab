# AI 实验状态快照

仅为清单中的 70 个 `physics-middle/初中物理实验*.html` 接入。物理科普和其他学科不发送状态。

## 行为与边界

- 点击发送后，App 向当前实验 iframe 请求一次快照，最多等待 800 ms；缺脚本、切页加载或失败时继续使用离线资料答疑。
- 快照含当前模式、状态、关卡、任务、提示，以及白名单中已存在的文字读数。实验 63 使用 `modeChip/stateChip/stepNo/taskTitle` 映射。
- 不采集表单值、聊天输入、页面全文、截图、Canvas 像素、完整曲线或操作历史。Canvas 独有读数没有对应文字节点时保持未知。
- 快照反映提问时刻；AI 回答时实验可能已继续运行。自由/演示模式下，保留的关卡文字不能被当作必须执行的目标。
- 状态仅随本次问题发送，不写入浏览器聊天历史或服务端日志。后续提问重新采样；此前回答中的状态描述不作为最新状态。
- 内置 API 与自定义服务模式均支持；界面告知是否成功取得本次状态，并说明数据会发送至对应模型服务。

## 文件与协议

内容仓库的 `experiment-ai-state.v1.js` 由 70 页各引用一次。使用独立 `science-lab.experiment-state.v1` 通道，沿用现有跨域 `postMessage` 通信方式，不改变滚动通道和实验状态机。

App 的 `ai-chat.js` 校验窗口、来源、随机请求标识、实验路径和字段边界。接收端只回应父窗口及正式 App 来源；本地验证允许两端均为 loopback HTTP(S)。请求结束、超时、取消或 iframe 加载时移除监听器，不缓存快照。

内置请求保持 `context.experimentPath`，可选增加 `context.liveState`。`server/api/ai-live-state.js` 白名单复制字段：5 个有界文字字段、最多 16 个读数（标签 40 字、值 100 字）；丢弃超过 30 秒、超前超过 5 秒、跨实验或不合法的快照，退回文字答疑。客户端时钟偏差过大也会回退。客户端状态是参考数据，不是可信测量或通关认证。
